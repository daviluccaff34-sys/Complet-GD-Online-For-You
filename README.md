# Complet GD Online For You!

A Geode mod for Geometry Dash, developed first for Android.

## Target compatibility

- Geode: **v5.11.2**
- Geometry Dash: **2.2081**
- Platform: **Android 64-bit** (initial target)

## Planned systems

- Online rooms and multiplayer with friends
- Collaborative level editing
- Cloud-backed level and project storage
- An AI assistant that explains Geometry Dash triggers
- Integration with the project's online services

## Development policy

The project is developed through GitHub. GitHub Actions will be used for checks and, later, Android builds. **Compilation and release are intentionally postponed** until the source, SDK configuration, dependencies, and feature implementations have been reviewed.

This repository is an independent community project and is not affiliated with RobTop Games or the Geode team.
